# 투명 움짤 메이커

배경이 투명한 PNG 프레임 여러 장을 순서대로 이어서, 배경이 투명한 움짤(GIF · APNG · WebP) 한 장으로 만드는 웹페이지예요.

- 넣은 그림은 **브라우저 안에서만** 처리돼요. 어디에도 업로드되지 않아요.
- 다운로드는 브라우저 기본 저장이라, 파일에 출처 정보 같은 **추가 정보가 붙지 않아요.**
- GIF는 무한 반복 설정이 파일 맨 앞에 들어가서 PC 뷰어에서도 반복돼요.

## GitHub Pages로 올리기 (웹사이트에서만, 설치 없음)

1. **저장소 만들기**
   [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name: 예) `umjjal-maker`
   - **Public** 선택 (무료 계정은 공개 저장소에서만 Pages를 쓸 수 있어요. 공개되는 건 코드뿐이고, 페이지에 넣는 그림은 올라가지 않아요.)
   - **Create repository** 클릭

2. **파일 올리기**
   새 저장소 화면에서 **uploading an existing file** 링크를 누르거나 **Add file → Upload files**
   → `index.html`과 `README.md`를 끌어다 놓기 → 아래 초록색 **Commit changes** 클릭

3. **Pages 켜기**
   저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
   → **Build and deployment** 아래 **Source**를 **Deploy from a branch**로
   → **Branch**에서 `main`, 폴더는 `/ (root)` 선택 → **Save**

4. **접속하기**
   보통 1~2분, 길면 10분쯤 지나면 같은 Pages 화면 위쪽에
   `Your site is live at https://아이디.github.io/umjjal-maker/`
   가 떠요. 그 주소를 즐겨찾기해 두고 쓰면 돼요.

## 쓰는 법

1. **PNG 넣기**: 프레임 PNG를 한꺼번에 끌어다 놓거나 고르면 파일 이름 순서(1, 2, … 10, 11)로 들어가요. 순서는 끌어서 바꿀 수 있어요.
2. **확인하기**: 미리보기와 아래 타이밍 칸에서 움직임을 확인해요.
3. **설정**: 전체 재생 시간(기본 1초), 반복, 형식, 크기를 골라요.
4. **만들고 저장**: **GIF 만들기**를 누른 다음 **다운로드**를 눌러요.

### 형식 고르기

| 형식 | 장점 | 주의할 점 |
|---|---|---|
| GIF | 어디서나 재생돼요 | 픽셀이 완전 투명 아니면 불투명이라 반투명한 테두리는 정리돼요 |
| APNG (.png) | 반투명까지 원본 그대로 | 용량이 크고, 일부 앱에선 첫 장만 보여요 |
| WebP | 반투명 + 가장 작은 용량 | 일부 앱은 재생하지 못해요. 사파리에선 만들 수 없어요 |

### 알아 두면 좋은 것

- **정확히 1초**: GIF는 1/100초 단위라 15장을 똑같이 나눌 수 없어요. 그래서 0.07초와 0.06초를 섞어 합계를 정확히 1.00초로 맞춰요.
- **GIF 테두리**: GIF 세부 설정의 **투명 기준**과 **반투명 테두리에 섞을 배경색**으로 테두리를 다듬을 수 있어요. 미리보기에 바로 반영돼요.
- **용량**: 3800×1500 같은 큰 GIF는 10MB가 넘을 수 있어요. 올릴 곳에 용량 제한이 있으면 출력 크기를 50%로 줄여 보세요(대략 1/4로 줄어요).
- **권장 브라우저**: 최신 크롬 · 엣지 · 웨일

## 페이지 고치기 · 바꾸기

새 `index.html`을 받으면 같은 저장소에서 **Add file → Upload files**로 다시 올리고 **Commit changes**를 누르면 돼요. 몇 분 뒤 같은 주소에 반영돼요.
